## 🇬🇧 English Description

**Fox Lamp** is a cozy decorative mod for Minecraft (Fabric 1.21.4) that adds a craftable lamp shaped like a sleeping fox.
I created this project from scratch: modeling in **BlockBench** and coding the logic manually.

### ✨ Features
* **Interactive:** Right-Click (**RMB**) the lamp to toggle the light ON or OFF.
* **Shader Friendly:** The model uses a special **translucent texture**. This creates a beautiful, soft glowing effect (subsurface scattering look) when used with shaders.
* **Survival Ready:** Fully craftable in survival mode.

## 🇷🇺 Описание на Русском

**Fox Lamp** — это уютный декоративный мод для Minecraft (Fabric 1.21.4), добавляющий лампу в виде спящей лисички.
Проект сделан с нуля: модель нарисована в **BlockBench**, а код написан вручную.

### ✨ Особенности
* **Интерактивность:** Нажмите ПКМ (**RMB**) по лампе, чтобы включить или выключить свет.
* **Поддержка шейдеров:** Модель использует уникальную **полупрозрачную текстуру**. Благодаря этому с включенными шейдерами лампа выглядит особенно красиво, создавая эффект мягкого свечения (как настоящее матовое стекло или воск).
* **Выживание:** У лампы есть крафт, её можно создать в обычном режиме игры.
